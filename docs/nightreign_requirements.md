# 要件定義書: ELDEN RING NIGHTREIGN ボス特定アプリ (仮称)

## 1. プロジェクト概要

### 1.1 目的

「ELDEN RING NIGHTREIGN」の「深き夜」モードにおいて、1 日目・2 日目のボス出現情報から、最終日（3 日目）に出現する「夜の王」を予測・特定するツールを提供する。

### 1.2 ターゲットユーザー

- 「深き夜」モードを攻略中のプレイヤー
- 効率的に周回を行いたい熟練プレイヤー
- スマートフォンで手軽に情報を確認したいユーザー

### 1.3 提供形態

- **Web アプリケーション (PWA)**
  - PC、スマートフォン（iOS/Android）のブラウザで動作。
  - アプリのようにホーム画面に追加可能（PWA 対応）。

## 2. 機能要件

### 2.1 ボス選択・絞り込み機能

- **1 日目のボス選択**:
  - リストから 1 日目のボスを選択できる。
  - 選択すると、2 日目のボス候補が絞り込まれる。
  - 選択すると、3 日目のボス候補（予測結果）が表示される。
- **2 日目のボス選択**:
  - 1 日目の選択に基づき、あり得る 2 日目のボスのみを選択肢として表示する。
  - 選択すると、3 日目のボスが（可能なら 1 つに）特定される。
- **リセット機能**:
  - 選択状態を初期化し、最初からやり直せるボタン。

### 2.2 結果表示機能

- **3 日目のボス候補表示**:
  - 現在の選択状況から考えられる 3 日目のボスを表示する。
  - 候補が複数の場合はリスト表示。
  - 候補が 1 つに確定した場合は強調表示（「確定！」などの演出）。
- **詳細情報表示 (Optional)**:
  - ボスの弱点属性や有効な戦術などの簡易メモを表示（将来拡張）。

### 2.3 データ管理機能

- **JSON ベースのルーティングデータ**:
  - ボス出現パターンを JSON ファイルで管理。
  - アプリの再ビルドなしに（または簡単な更新で）データを修正可能にする構造。

## 3. 非機能要件

### 3.1 UI/UX デザイン

- **世界観の踏襲**:
  - ゲームの雰囲気に合わせた「ダークモード」ベースのデザイン。
  - 高級感、神秘的な雰囲気（黒、金、暗い青などを基調）。
- **モバイルファースト**:
  - スマホでの操作性を最優先（大きなタップ領域、片手操作）。

### 3.2 パフォーマンス

- **即時応答**:
  - 選択操作に対してラグなく候補が絞り込まれること（クライアントサイドで完結）。

## 4. データモデル（案）

### 4.1 Boss Entity

```typescript
interface Boss {
  id: string;
  name: string; // 日本語名
  type: 'day1' | 'day2' | 'day3';
  imageUrl?: string; // 将来的に画像を表示する場合
}
```

### 4.2 Route Definition

```typescript
interface Route {
  day1Id: string;
  day2Id: string;
  day3Id: string;
}
// またはツリー構造
```

## 5. 決定事項（ユーザー様確認済み）

1.  **ボスの入力方法**: リスト選択のみ（テキスト検索なし）。
2.  **不明なパターンの扱い**: 「データなし」と表示する。
3.  **画像素材**: テキストのみで実装する（画像は使用しない）。
